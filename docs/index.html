Частые вопросы

Нужен ли купленный Minecraft?

Нет. Достаточно ввести ник — лаунчер запустит игру в офлайн-режиме и сам скачает нужную версию.

Нужен ли аккаунт Microsoft?

Нет. Лаунчер не просит пароли и не передаёт данные: работает по нику, всё хранится локально на твоём компьютере.

Какие версии Minecraft поддерживаются?

Все релизные версии, доступные в официальном списке. Плюс Fabric и Forge для модпаков.

На какой ОС работает?

Windows 10 и 11 (x64). Для сборки из исходников нужен Python 3.10+.

Где взять исходники?

В репозитории на GitHub — там же инструкции по сборке `.exe` через PyInstaller.
