Частые вопросы

Нужен ли купленный Minecraft?

Для входа через Microsoft и игры на официальных серверах — да. Для офлайн-режима можно указать ник без покупки, но доступны будут только офлайн-миры.

Это безопасно? Куда уходит мой аккаунт?

Логин проходит на официальном сайте Microsoft. Лаунчер не получает и не передаёт твой пароль. Токен доступа хранится только локально на твоём компьютере.

Какие версии Minecraft поддерживаются?

Все релизные версии, доступные в официальном списке. Плюс Fabric и Forge для модпаков.

На какой ОС работает?

Windows 10 и 11 (x64). Для сборки из исходников нужен Python 3.10+.

Где взять исходники?

В репозитории на GitHub — там же инструкции по сборке `.exe` через PyInstaller.
